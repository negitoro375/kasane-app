# KASANE — 公開用ファイル

[アプリを開く](https://negitoro375.github.io/kasane-app/)

画像をブラウザで色ごとに切り分け、透過PNG・PSD・編集用プロジェクトに保存するアプリです。

このリポジトリにはビルド済みの公開用ファイルと配信設定だけを置いています。開発ソースは別の非公開リポジトリで管理しています。利用者の画像やプロジェクトファイルは含めません。

- 自動保存は、その端末・ブラウザで作業中の1件です。操作履歴は保存しません。
- 端末を移るときは `.kasane` ファイルをiCloud Driveなどへ保存し、移動先のアプリから開きます。
- 画像・選択マスク・プロジェクトをサーバーへ送信する機能はありません。外部フォントや既存プラットフォームのスクリプトへの通信はあります。
